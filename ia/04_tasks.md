# 04 — Índice de Tareas

El trabajo accionable vive en `04_tasks/`:

| Archivo o carpeta | Contenido |
|--------------------|-----------|
| `04_tasks/current.md` | Tareas `Borrador`, `Lista`, `En progreso` y `Bloqueada` |
| `04_tasks/backlog.md` | Ideas y trabajo diferido sin aprobar |
| `04_tasks/blocked.md` | Notas de tareas bloqueadas de larga duración (el estado vive en la tarea) |
| `04_tasks/tasks/` | Un archivo por tarea activa: `TASK-{INICIALES}-{AREA}-{NN}.md` |
| `04_tasks/done/` | Historial mensual de tareas completadas: `YYYY-MM.md` |

Ver el ciclo de vida completo, la convención de ID y el template de tarea en
`references/04-tasks.md` del skill `ia-workflow`.
